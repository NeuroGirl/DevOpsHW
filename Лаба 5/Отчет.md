## Со звездочкой:

Сначала создадим правило, которое будет вызывать алерт. Сделаем простой сценарий: если у любого пода CPU usage > 80% более 1 минуты,
бросаем алерт.

```
apiVersion: monitoring.coreos.com/v1
kind: PrometheusRule
metadata:
  name: high-cpu-alert
  namespace: monitoring
  labels:
    prometheus: monitor
spec:
  groups:
  - name: my-app-alerts
    rules:
    - alert: HighCpuUsage
      expr: sum(rate(container_cpu_usage_seconds_total{image!="", container!="", namespace="default"}[5m])) by (pod) > 0.8
      for: 1m
      labels:
        severity: warning
        team: devops
      annotations:
        summary: "High CPU usage"
        description: "Some pod in namespace is using more than 80% CPU for the last 1 minute."
```

Применяем его

```
minikube kubectl -- apply -f alert-high-cpu.yaml
```

Чтобы проверить алерт, нагружаем под (любой) бесконечным циклом для достижения 100% CPU и отправки алерта

```
yes > /dev/null &
```
