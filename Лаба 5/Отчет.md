# Лабораторная работа №5: Мониторинг (Это база, это base)

## Обычная:

Запускаем кластер Minicube и устанавливаем стек мониторинга

```
minikube start --driver=docker --memory 4096 --cpus 2
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm repo update
```

Также создаем файл настроек helm

```
nano settings.yaml
```

```
grafana:
  image:
    repository: grafana/grafana
    tag: 10.4.2
    pullPolicy: IfNotPresent

prometheus:
  prometheusSpec:
    image:
      repository: prom/prometheus
      tag: v2.47.0
      pullPolicy: IfNotPresent
    configReloaderImage:
      repository: quay.io/prometheus-operator/prometheus-config-reloader
      tag: v0.90.1
```

Создаем отдельное пространство имен monitoring и запускаем поды

Как видим все работает - это хорошо, значит можно пробрасывать порты

```
minikube kubectl -- port-forward svc/monitor-grafana -n monitoring 3000:80
```

<img width="1277" height="593" alt="image" src="https://github.com/user-attachments/assets/0158c7b8-7f25-4df4-8533-6f85666e6ec6" />

Ой ой пароля то мы не знаем. Ctrl + C закрываем проброс  портов и получаем пароль

```
minikube kubectl -- get secret monitor-grafana -n monitoring -o jsonpath="{.data.admin-password}" | base64 --decode; echo
```
